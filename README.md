# Markdown to SVG CLI Converter

This tool allows you to translate Markdown documents into fully functional SVG text files with full Markdown formatting support. The oriiginal goal of this project was to allow inserting Markdown into KDENLive directly, but it is a generic translation into SVG that should be suitable for any other purpose.
